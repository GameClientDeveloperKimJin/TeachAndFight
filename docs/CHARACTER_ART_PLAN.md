## 2. 공통 스타일 가이드 (전원 필독 — 6명이 한 게임처럼 보이려면 이거 어겨선 안 됨)

- **화풍**: 2D 플랫 카툰(벡터 느낌, 두꺼운 외곽선 1~2px, 단순 음영 1단만). 픽셀아트 금지 — 서로 다른 사람이 AI로 여러 장 생성했을 때 픽셀아트는 그리드/팔레트가 미묘하게 어긋나기 쉬움, 플랫 카툰이 일관성 유지에 더 관대함.
- **캔버스/비율**: 정사각 1024×1024 소스로 생성 → Sprite Editor에서 실제 판정 박스 비율(세로가 긴 사람 형태, `MatchScreenController`의 placeholder 비율 `0.8 x 1.8` 참고)에 맞게 크롭.
- **시점**: 완전 횡스크롤 사이드뷰(2D 격투 게임 기준), 캐릭터는 항상 오른쪽을 보는 기본형으로 제작(좌우 반전은 코드가 `FacingRight`로 처리 — 별도로 왼쪽 보는 버전 만들 필요 없음).
- **배경**: 완전 투명(PNG alpha) 또는 단색 배경 후 배경제거.
- **비율**: 전원 동일한 머리-몸 비율(2.5~3등신 데포르메 권장, 6명 다 똑같이) — 한 명만 사실적 비율로 만들면 나란히 세웠을 때 어색함.
- **외곽선 두께/선굵기**: 전원 동일 값 — AI 프롬프트에 매번 "동일한 두께의 검은 외곽선, 1~2px" 명시.
- **팔레트 규칙**: 캐릭터 구분은 큰 실루엣 차이 + 대표 악센트 컬러 1개로. 아래 3번 표의 "악센트 컬러" 참고.
- **조명**: 정면光, 그림자 최소화(음영이 강하면 애니메이션 프레임 간 깜빡임 발생).

## 3. 캐릭터별 컨셉 (AI 이미지 생성 프롬프트 소재)

### 제자 (Disciple) — KJ 담당
- **컨셉**: 성실하고 약간 어리숙한 견습생. 아직 미완성인 실력, 순수한 눈빛, 낡았지만 단정한 도복.
- **실루엣**: 마르고 곧은 자세, 어깨 살짝 움츠림(자신감 부족 표현).
- **악센트 컬러**: 흰색/연한 하늘색 도복 + 갈색 벨트.
- **소품**: 없음(맨몸 격투) 또는 손목 붕대.

### 러쉬 (Rush) — KJ 담당
- **컨셉**: 스태미나 관리 없이 닥돌하는 저돌적 파이터. 성급하고 다혈질.
- **실루엣**: 앞으로 쏠린 전투 자세, 항상 돌진 직전처럼 무게중심이 앞발에.
- **악센트 컬러**: 빨강/주황.
- **소품**: 손에 감은 붕대/글러브, 헝클어진 스파이크 머리.

### 철벽 (Iron Wall) — JM 담당
- **컨셉**: 선공 없이 버티는 방어형. 둔중하고 흔들림 없음.
- **실루엣**: 넓고 낮은 자세, 두꺼운 몸통, 정지 상태에서도 안정감.
- **악센트 컬러**: 청회색/철색.
- **소품**: 두꺼운 보호대(팔뚝/정강이), 방패 느낌의 팔짱/가드 자세.

### 그림자 (Shadow) — JM 담당
- **컨셉**: 반응형 카운터. 상대 공격 낌새에 회피 대시 후 처벌. 은밀하고 날렵함.
- **실루엣**: 마르고 낮은 무게중심, 반쯤 웅크린 대기 자세.
- **악센트 컬러**: 보라/검정.
- **소품**: 후드/망토, 얼굴 가림(눈만 보임).

### 카멜레온 (Chameleon) — KJ 담당
- **컨셉**: `time_left` 페이즈에 따라 돌격→방어→올인으로 바뀌는 변칙형. 이중적/불안정한 인상.
- **실루엣**: 좌우 비대칭 요소(한쪽은 공격적, 한쪽은 방어적 디테일)로 이중성 암시.
- **악센트 컬러**: 그라디언트 녹색↔보라 (비늘/파충류 모티브).
- **소품**: 얼굴 절반 가면 또는 비늘 패턴 스카프.

### 사범 (Master) — JM 담당
- **컨셉**: 5차전 최종 보스. 1~4차전 상대 기술을 전부 정제해 조합한 완성형. 위엄있고 노련함.
- **실루엣**: 가장 크고 안정된 체격, 곧은 자세, 관록.
- **악센트 컬러**: 짙은 적색+금색(단증/사범 벨트 색).
- **소품**: 수련 도복 위 단(段) 표식, 긴 허리끈.

## 5. AI 생성 워크플로 가이드 (일관성 유지 팁)

1. **베이스 프롬프트 템플릿 고정** — 2번 공통 스타일 문구를 항상 그대로 포함하고, 캐릭터별 컨셉 문장만 교체. 두 사람 다 같은 템플릿 사용할 것(문서 하단에 템플릿 예시).
2. **Idle 포즈부터 먼저 확정** — 캐릭터당 Idle 1장을 "기준 이미지"로 먼저 뽑고, 나머지 7개 클립은 그 기준 이미지를 레퍼런스(img2img/이미지 첨부)로 넣어 생성 — 프레임마다 캐릭터가 다른 사람처럼 보이는 사고 방지.
3. **한 클립 = 여러 장 생성 후 선별** — 클립당 후보 2~3장 뽑아서 자세/실루엣 일관성 제일 좋은 것 채택.
4. **Sprite Editor 슬라이스**: 생성된 각 프레임 PNG를 개별 임포트 후 Unity Animation 창에서 클립으로 묶는 방식(스프라이트시트 한 장에 다 넣지 않아도 됨 — 개별 PNG 시퀀스가 AI 생성 특성상 더 다루기 쉬움).
5. **좌우 반전 버전 만들지 말 것** — 전부 오른쪽을 보는 기본형만 생성. 왼쪽 반전은 `FighterAnimatorBridge`가 `FacingRight` 값으로 `SpriteRenderer.flipX` 처리(코드 담당 JM).

### 베이스 프롬프트 템플릿 (예시)

```
2D flat cartoon game character, side view facing right, thick black outline (1-2px),
single-tone flat shading, transparent background, deformed 2.5-head proportions,
fighting game sprite style, [캐릭터별 컨셉 문장 삽입], [클립별 포즈 힌트 삽입],
consistent art style across a full animation set
```

```
Assets/_Shared/Art/Characters/
  Disciple/        (제자, KJ)
    Idle/, Move/, Dash/, AttackLight/, AttackHeavy/, AttackUltimate/, HitStun/, Down/
  Rush/            (러쉬, KJ)
```
