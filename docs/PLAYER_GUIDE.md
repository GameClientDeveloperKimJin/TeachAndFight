# TeachAndFight 플레이 가이드

> 이 문서는 **플레이어(코치) 관점** 가이드다. 개발 스펙은 `DEV_SPEC.md`, 진행상황은 `IMPLEMENTATION_PLAN.md` 참고.
> 기준 시점: 어휘 확장(#26) + 밸런스 패치(counter_attack 분리, 슬롯 9개) 반영 후.

## 0. 상대별 확실하게 이기는 티칭

### 공통 코어 (제일 먼저 가르칠 것 — 대부분 상대에 통용)

| 순서 | 티칭 문장 | 이유 |
|---|---|---|
| 1 | "상대가 궁 쓰면 대시로 피해" | 전 상대 공통, 최우선 — 궁 한 방이 제일 아픔 |
| 2 | "상대가 공격 준비하면 반격기를 써" | `attack_startup`(약공/강공 둘 다) 감지 — 반격기는 발동 0.08초로 빨라서 상대보다 먼저 맞출 여지 있음 + 보너스 데미지(×1.5) |
| 3 | "거리 1.5 안에 있으면 반격기를 써" | 상대가 공격 안 해도 안전하게 딜 넣는 메인 수단 — 반격기는 애니메이션이 약공으로 위장돼 있어서 대부분 상대의 "견제/회피" 반응 규칙에 안 걸림 |
| 4 | "거리 1.5보다 멀면 대시로 다가가" | `approach`(걷기)는 도망형 상대의 "접근 견제" 조건에 걸리고, 상대와 이동속도가 같아서 거리가 아예 안 좁혀지는 경우도 있음 — 대시로 우회 |
| 5 | "대시 못 쓸 때는 걸어서 접근해" | 대시 쿨다운(1초) 도는 동안의 폴백. **꼭 넣을 것** — 빠지면 교착 상태 남 |
| 6 | "스태미나 20% 밑이면 쉬어" | 자원 관리 안전장치 |

슬롯 9개 중 6개 사용. **강공은 의도적으로 안 가르침** — 몇몇 상대가 강공 낌새를 감지해서 회피하므로 오히려 헛치기 쉬움. 반격기 하나로 딜을 몰아주는 게 안전.

### 상대별 추가 사항

| # | 이름 | 코어만으로 충분? | 추가 티칭 |
|---|---|---|---|
| 1 | 러쉬 | ✅ | 없음 — 방어 자체가 없는 상대라 코어만으로 압살 |
| 2 | 철벽 | ✅ | 없음 — 대시 접근이 핵심이었는데 이미 코어에 있음 |
| 3 | 그림자 | ✅ | 없음 — 강공을 안 쓰니 "강공 회피" 반응 자체가 안 걸림 |
| 4 | 카멜레온 | ⚠️ | "시간이 17초 이하일 때 상대가 공격 준비하면 반격기를 써" (후반 강공 스팸 대비, 없어도 코어가 어느 정도 커버는 함) |
| 5 | 사범(보스) | ✅ | 없음 — 사범은 "강공 낌새 회피"·"접근 시 견제" 두 반응 규칙이 있는데 반격기는 둘 다 안 걸리는 사각지대라 코어 그대로 통함 |

**결론**: 코어 6개(+카멜레온용 1개, 총 7개)면 5명 전부 커버. 슬롯 2개는 여유로 남겨둘 것.

## 1. 제자가 쓸 수 있는 행동(스킬) 설명

가르친 규칙의 `do.action`에 들어갈 수 있는 값들. 괄호 안은 `Resources/Data/Config/combat_config.json` 기준 실제 수치.

| 행동 | 설명 | 데미지 | 사거리 | 발동(startup) | 회복(recovery) | 스태미나 |
|---|---|---|---|---|---|---|
| `approach` | 상대 쪽으로 이동 | - | - | - | - | 무료 |
| `retreat` | 상대 반대쪽으로 이동 | - | - | - | - | 무료 |
| `keep_distance(range)` | 지정한 거리(m)를 유지하려고 앞뒤로 움직임 | - | - | - | - | 무료 |
| `dash(direction: toward\|away)` | 순간적으로 빠르게 이동(0.2초에 2.5m). **처음 0.15초는 무적** | - | - | - | - | 20 |
| `idle` | 제자리 대기. 가만히 있을 때 스태미나 회복이 2배(30/초, 다른 상태는 15/초) | - | - | - | - | 무료 |
| `light_attack` | 기본 공격 | 8 | 1.2 | 0.15초 | 0.25초(명중)/0.35초(헛침) | 10 |
| `heavy_attack` | 강한 공격 | 20 | 1.5 | 0.45초 | 0.50초(명중)/0.90초(헛침) | 25 |
| `ultimate` | 궁극기. 궁극기 게이지 100% 필요(가하거나 맞은 데미지만큼 참) | 35 | 2.0 | 0.60초 | 0.70초(명중)/1.20초(헛침) | 게이지 소모 |
| `counter_attack` | **반격기**. 상대가 공격 준비 중일 때 쓰면 데미지 1.5배(8→12). 애니메이션은 기본공격과 똑같이 보여서 상대가 "이게 반격기인지" 구분 못 함 | 8(보너스 시 12) | 1.5 | **0.08초**(제일 빠름) | 0.25초(명중)/0.35초(헛침) | 15 |
| `feint` | **페인트**. 데미지 없음. 기본공격처럼 보이지만 실제로는 안 때리고 빠르게 빠짐(회복 0.15초로 매우 짧음) — 상대를 낚는 용도 | 0 | - | 0.15초(기본공격과 동일해서 위장됨) | 0.15초(빠름) | 5 |

**팁**: `counter_attack`과 `feint` 둘 다 겉보기엔 기본공격(`light_attack`)과 똑같이 보임 — 상대 AI가 "이건 반격기다/페인트다"를 구분할 방법이 없어서, 상대의 반응 규칙(예: "강공 낌새엔 회피")을 우회하는 용도로 특히 강력함.

## 2. 제자에게 가르칠 수 있는 어휘/규칙 문법

### 규칙의 기본 구조
한 규칙은 **"조건(when) → 행동(do)"** 형태. 코치가 자연어로 말하면 제자(LLM)가 이 형태로 번역해서 규칙 슬롯에 저장한다.

- 조건은 **AND로만 결합** 가능(OR 표현 불가)
- **가르침 1번 = 규칙 1개**가 원칙. "A거나 B면"처럼 OR 뜻이 담긴 문장은:
  - `attack_startup`으로 하나로 합칠 수 있으면 그렇게 처리(아래 참고)
  - 안 되면 조건 하나만 골라달라고 되물음
- **"A면 B하고 C면 D해줘"**처럼 서로 다른 규칙 2개를 한 문장에 담으면: 첫 번째(A→B)만 먼저 규칙으로 추가하고, 두 번째(C→D)는 "그것도 가르쳐드릴까요?" 하고 따로 되물음 — 다음 턴에 "응"이라고 답하면 그때 추가됨
- 규칙 슬롯은 최대 **9개**(현재 기준)

### 조건(when)에 쓸 수 있는 값(fact)

| fact | 뜻 | 범위 |
|---|---|---|
| `self_hp_pct` | 내 체력 % | 0~100 |
| `self_stamina_pct` | 내 스태미나 % | 0~100 |
| `self_ult_gauge` | 내 궁극기 게이지 % | 0~100 |
| `enemy_hp_pct` | 상대 체력 % | 0~100 |
| `enemy_stamina_pct` | 상대 스태미나 % | 0~100 |
| `distance` | 상대와의 거리(m) | 0~12 |
| `time_left` | 남은 시간(초) | 0~60 |
| `enemy_action` | 상대가 지금 뭘 하고 있는지 | 아래 상태값 참고 |
| `self_action` | 내가 지금 뭘 하고 있는지 | 아래 상태값 참고 |
| `self_wall_dist` | 등 뒤 벽까지 거리(m) — 코너 압박 판정용 | 0~6 |
| `self_action_duration` | 지금 내 행동을 얼마나 오래 하고 있는지(초) | 0~60 |
| `enemy_action_duration` | 지금 상대 행동이 얼마나 오래 지속됐는지(초) | 0~60 |
| `enemy_whiff_count` | 최근 5초 내 상대가 헛스윙한 횟수 | 0~20 |

### `enemy_action` / `self_action`이 가질 수 있는 상태값
`idle`(대기), `approach`(다가옴), `retreat`(물러남), `light_startup`(약공 준비), `heavy_startup`(강공 준비), `ultimate_startup`(궁 준비), `dash`(대시 중), `whiff_recovery`(헛치고 회복 중), `hit_stun`(맞고 경직)

+ **`attack_startup`**(특수값): `light_startup` 또는 `heavy_startup` 아무거나 매칭되는 포괄 값. "공격 준비하면"처럼 약공/강공을 굳이 구분 안 해도 될 때 규칙 1개로 쓸 수 있게 해줌(궁은 제외 — 궁은 보통 회피가 따로 있어서).

### 비교 연산자(op)
`==`, `!=`, `>`, `<`, `>=`, `<=` — 단, 문자열 값(`enemy_action`, `self_action`)은 `==`, `!=`만 가능.

### 예시 문장 → 실제로 이렇게 자연스럽게 말하면 됨
- "상대가 궁 쓰면 대시로 피해" → `enemy_action == ultimate_startup` → `dash(away)`
- "체력 30% 밑이면 쉬어" → `self_hp_pct < 30` → `idle`
- "코너에 몰리면 반격해" → `self_wall_dist <= 1` (LLM이 예시로 물어보며 확정) → `counter_attack`
- "적이 계속 헛치면 강공으로 처벌해" → `enemy_whiff_count >= 2` → `heavy_attack`

모호한 문장(수치 불명확 등)이면 제자가 구체적으로 되물어봄(예: "1.2 정도 거리를 말씀하시는 건가요?"). 완전히 새로운 개념(어휘에 없는 것)을 요구하면 "그건 제가 할 수 있는 게 아닌데요..." 하고 거절함.

## 3. 상대(적) 5종 행동 패턴

상대는 제자와 **완전히 동일한 규칙 시스템**으로 움직인다(별도 AI 코드 없음) — 즉 상대도 위 2번 어휘로 만들어진 규칙셋을 그대로 따를 뿐이다.

| # | 이름 | 성격 | 행동 패턴 |
|---|---|---|---|
| 1 | **러쉬** | 돌격형 | 멀면 무조건 다가오고, 사거리(1.2) 안이면 무조건 약공. 방어/후퇴 개념 자체가 없음. 궁 차면 즉시 사용 |
| 2 | **철벽** | 거북이형 | 거리 3m 안이면 무조건 후퇴(선공 없음). 내가 헛치면 강공으로 확실히 처벌. 내가 걸어서(approach) 1.5 안까지 다가가면 약공으로 견제. 스태미나 30% 밑이면 쉼 |
| 3 | **그림자** | 카운터형 | 내가 강공 준비하면 즉시 대시로 회피. 내가 헛치면 강공으로 처벌. 궁 차면 즉시 사용. 평소엔 거리 2.5m 유지하며 맴돎 |
| 4 | **카멜레온** | 변칙형 | 시간에 따라 성격이 3번 바뀜: **초반(40초 이상 남음)**엔 러쉬처럼 닥돌+약공, **중반(20~37초)**엔 철벽처럼 도망+헛침 처벌, **후반(17초 이하)**엔 닥돌+강공(더 위험). 페이즈 전환 직후 2~3초는 아무 규칙도 안 걸려서 잠깐 멈칫하는 틈이 있음(약점) |
| 5 | **사범(보스)** | 밸런스형 | 1~4번 상대의 핵심 패턴을 조합: 궁 즉시 사용, 강공 낌새엔 회피 대시(거리 2.0 이내), 헛치면 강공 처벌, 접근하면 약공 견제, 저체력(30% 밑)이고 궁 없으면 후퇴, 스태미나 넉넉하면 강공, 기본은 약공+닥돌. 단일 약점이 없어서 지금까지 배운 걸 종합적으로 써야 함 |

공통적으로 상대는 **내 행동(enemy_action 관점에서 보면 "나"의 상태)에 반응하는 규칙**을 갖고 있는 경우가 많다 — 즉 내가 어떤 동작(approach/heavy_startup 등)을 보이느냐에 따라 상대 반응이 달라진다. 이 때문에 "겉보기엔 기본공격과 똑같은" 반격기/페인트가 상대 반응 규칙을 우회하는 데 특히 유용하다.

## 4. 신규 유저를 위한 시작 가이드

### 이 게임이 뭐 하는 게임인가
**당신은 직접 싸우지 않는다.** 당신은 코치고, "제자"라는 캐릭터에게 **한국어 문장으로 규칙을 가르치면**, 그 규칙에 따라 제자가 **완전 자동으로** 전투를 치른다. 실시간 조작 없음 — 얼마나 잘 가르쳤는지가 곧 실력이다.

### 화면 흐름
1. **훈련실(Training)**: 채팅창에 자연어로 가르침 입력 → 제자가 이해한 대로 되묻거나 규칙을 슬롯에 추가함 → 규칙 슬롯 목록에서 확인/삭제 가능 → 준비되면 [경기 시작]
2. **경기(Match)**: 가르친 규칙대로 제자가 자동으로 싸움. 배속 조절/일시정지 가능. 결과(승/패) 확인
3. **락커룸(LockerRoom)**: 경기 결과 + 제자의 회고 대사 + 어떤 규칙이 몇 번 발동했는지 통계 확인. 다음 상대로 진행하거나 재대결

### 처음 할 때 알아둘 것
- **규칙 슬롯은 9개까지만** — 무한정 가르칠 수 없으니 중요한 것부터
- **조건은 AND만 가능** — "A거나 B면" 같은 문장은 규칙 하나로 표현이 안 돼서 되묻거나 두 번에 나눠 가르쳐야 함
- **우선순위(priority)가 있다** — 여러 규칙 조건이 동시에 맞으면 우선순위 높은 게 먼저 발동. 구체적인 상황(예: "궁 쓰면 피해")은 우선순위를 높게, 평범한 행동(예: "멀면 다가가")은 낮게 잡는 게 좋음(제자가 알아서 배정하긴 하지만 이해해두면 슬롯 관리에 도움됨)
- **모호하게 가르치면 제자가 되물음** — "거리 좀 멀면"처럼 애매하면 실제 사거리(약공 1.2 / 강공 1.5) 기준으로 되물어봄. 구체적으로 답해줄 것
- **스태미나/쿨다운 자원 관리 필수** — 공격은 전부 스태미나를 쓰고(대시도 마찬가지), 부족하면 그 규칙은 자동으로 스킵되고 다음 우선순위 규칙으로 넘어감. "쉬어" 규칙 하나쯤 넣어두는 게 안전함
- **가르친 규칙은 상대가 바뀌어도 유지됨** — 매 상대마다 규칙셋이 리셋되지 않으니, 이전에 가르친 게 다음 상대한테도 계속 적용됨(좋을 수도 나쁠 수도 있음 — 필요하면 규칙 슬롯에서 직접 삭제 가능)
- **화면에 아무 반응 없어 보여도 버그 아닐 수 있음** — 일부 상대는 일부러 도망 다니거나 선공을 안 해서 한동안 안 부딪힐 수 있음(교착 상태 힌트 문구가 뜸). 그럴 땐 접근 수단(특히 대시)을 가르쳤는지 확인
- **첫 상대(러쉬)는 방어가 없어서 튜토리얼 성격** — 아무 규칙이나 가르쳐봐도 크게 안 위험하니 여기서 감을 익히는 걸 추천

### 제일 처음 추천하는 3줄
1. "상대가 궁 쓰면 대시로 피해"
2. "거리 1.5보다 멀면 접근해"
3. "거리 1.2 안이면 약공을 써"

이 3개로 러쉬부터 시작해서, 위 0번 섹션의 상대별 티칭으로 점점 확장해나가면 됨.
